# Rockin · entrenador d'acompanyament

Joc per aprendre a acompanyar cançons amb el teclat, seguint les cartes de ritme i de contorn melòdic de ROCKIN, amb una banda que acompanya.

**Per jugar:** obre la pàgina amb **Chrome o Edge** i, si tens un teclat MIDI, connecta'l abans d'obrir-la. També es pot tocar amb el ratolí o amb el teclat de l'ordinador («Tocar amb l'ordinador»).

- El progrés (alumnes, estrelles, camí) es guarda **al navegador de cada ordinador**.
- A la portada hi ha la **Guia del professorat** amb l'explicació de tot el joc.
- Sota la portada surt la versió; si una actualització no es veu, recarrega amb Cmd+Shift+R (Mac) o Ctrl+F5 (Windows).
